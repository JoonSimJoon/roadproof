# 주행기록

주행 중 촬영한 영상을 신고 자료로 정리하는 한국어 웹 편집기입니다. 영상 파일은 브라우저 안에서 처리하며 서버에 업로드하지 않습니다.

**[편집기 열기](https://joonsimjoon.github.io/roadproof/)** · [GitHub 저장소](https://github.com/JoonSimJoon/roadproof)

설치나 로그인 없이 휴대폰과 PC에서 같은 링크로 접속할 수 있습니다. 영상과 편집 설정은 기기 사이에 동기화되지 않습니다. 각 기기에서 편집할 파일을 직접 선택하세요.

## 사용

1. MP4 파일을 열거나 편집 영역에 끌어다 놓습니다. `샘플로 둘러보기`로 실제 촬영이 아닌 연습용 영상을 만들 수도 있습니다.
2. 시작·끝 슬라이더나 시간 입력으로 저장할 구간을 고릅니다. 재생 위치에서 `I`는 시작, `O`는 끝을 지정합니다.
3. **원본 영상 00:00의 실제 촬영 시각**을 한국 시간으로 입력하고 확인란을 체크합니다. 파일 수정 날짜를 촬영 시각으로 추정하지 않습니다. 필요 없다면 워터마크를 끕니다.
4. 워터마크 위치·크기·색상, 해상도, 소리 포함 여부를 고른 뒤 `MP4로 저장`을 누릅니다.
5. 현재 장면을 PNG로 저장하거나 장소·상황 메모를 복사/저장할 수 있습니다.

예: 원본이 2026-10-21 09:00:00에 시작하고 30~45초를 선택했다면 결과의 첫 장면은 09:00:30입니다. 표시 시각은 재생에 따라 증가하며 날짜가 넘어가는 경우도 반영합니다. 워터마크는 사용자가 입력한 시각이며 원본 촬영 시각을 인증하지 않습니다.

확대는 번호판과 장면을 확인하는 미리보기 기능입니다. 저장되는 MP4와 PNG에는 전체 화면이 들어갑니다. 원본 파일은 변경하지 않습니다. 메모와 영상은 새로고침 후 자동 복구되지 않으므로 필요한 결과를 저장하세요. 이 도구는 신고 자료를 편집하며 신고를 대신 제출하지 않습니다.

## 로컬 실행

Node.js 22 이상에서:

```sh
git clone https://github.com/JoonSimJoon/roadproof.git
cd roadproof
npm ci
npm run build
npm run dev
```

브라우저에서 http://localhost:4173 을 엽니다.

정적 결과물은 `dist/`입니다. 외부 CDN, API 키, 서버 측 영상 저장소가 필요 없습니다. HTTPS 또는 localhost에서 실행하세요.

## 호환성

최신 데스크톱 Chrome/Edge를 권장합니다. WebCodecs와 기기의 H.264 인코더가 필요하며 다른 브라우저는 운영체제와 코덱 지원에 따라 달라집니다. 입력 컨테이너는 MP4/MOV/WebM, 출력은 H.264 MP4입니다. 소리는 지원되는 경우 AAC로 보존/변환하며 처리할 수 없을 때는 안내를 표시합니다. 소리를 몰래 생략하지 않습니다.

모바일 화면도 지원합니다. 다만 실제 휴대폰의 MP4 저장 가능 여부는 브라우저와 하드웨어 코덱 지원에 달려 있습니다. 먼저 `샘플로 둘러보기`에서 짧은 구간 저장을 확인하세요. 모바일에서는 720p와 짧은 구간으로 시작하고, 지원하지 않는 코덱 안내가 나오면 PC에서 같은 링크를 열어 편집할 수 있습니다.

긴 4K 원본을 열 수 있지만 인코딩 속도와 최대 출력 크기는 기기 메모리와 코덱에 영향을 받습니다. 완성 MP4는 메모리에 만들어지므로 필요한 구간 위주로 저장하세요. 1080p/720p 옵션은 가로 영상의 높이, 세로 영상의 너비를 기준으로 축소하며 원본보다 확대하지 않습니다. 인코딩 중 탭을 닫지 마세요.

## 공개 배포

`main`에 변경을 push하면 [GitHub Actions](https://github.com/JoonSimJoon/roadproof/actions/workflows/pages.yml)가 의존성 설치, 테스트, 빌드를 거쳐 `dist/`를 GitHub Pages에 배포합니다. 실패한 테스트나 빌드는 배포되지 않습니다.

웹사이트와 소스 코드는 공개되지만, 사용자가 선택한 영상은 공개 저장소나 호스팅 서버로 전송되지 않습니다. 배포 결과물에는 앱 코드와 미디어 처리 라이브러리만 포함됩니다.

## 검증

```sh
npm test
node tests/media-browser.mjs
node tests/editor-browser.mjs
```

브라우저 테스트에는 로컬 Google Chrome이 필요합니다. UI 테스트는 `npm run dev`가 실행 중이어야 합니다. 개인 영상 없이 합성 샘플로 검사합니다.

검증 범위: 한국 시간과 날짜 경계, 선택 구간 계산, 실제 MP4 재디코딩, 자른 구간의 워터마크 시각, 오디오 보존/제거, 취소, PNG, UI 다운로드, 모바일 레이아웃.

미디어 처리는 [Mediabunny 공식 Conversion API](https://mediabunny.dev/guide/converting-media-files) 1.62.0을 사용합니다. 배포 파일에 라이선스를 포함합니다.
